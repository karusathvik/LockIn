# Locked In

A simple Chrome extension that allows you to filter out certain topics and block distracting websites, helping you stay focused.

## How to Use

1. Go to `chrome://extensions` in your Chrome browser.
2. Enable **Developer Mode** (top right).
3. Click **"Load unpacked"** and select the folder containing this extension.
4. Once loaded, click the Locked In icon and start blocking or filtering sites.

You can:
- Block specific domains
- Add topic-based keyword filters
- View and manage blocked/allowed lists in the settings panel

> **Note:** This extension was created specifically for my personal use — a custom tool to help me stay focused on work and avoid distractions.

## AI Integration

This extension uses the [Prompt API](https://developer.chrome.com/docs/extensions/ai/prompt-api) to intelligently classify pages based on content and block them if they match your filtered topics.
